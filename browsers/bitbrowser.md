## 免费版：10 个环境与每日操作额度

1. **可保存环境上限（10 个）**：账户内最多同时留存 10 个独立的浏览器环境配置文件。
2. **成员数量上限（1 人）**：免费版仅限单人账户使用，不支持添加额外团队成员或员工子账号协同操作。
3. **每日创建上限（20 个/天）**：每日最多新建 20 个环境，保存名额与每日创建次数分别计算。
4. **每日打开上限（50 次/天）**：每日所有环境的打开次数上限为 50 次。

## 代理检测、同步器、RPA、API 与 MCP

除了分别保存账号环境，比特浏览器还提供代理检测与多种自动化操作方式：

### 1. 代理配置与连接检测

每个环境可以绑定独立代理，并在启动前检测连接、目标地区与端口状态，方便发现失效代理或配置错误。已有其他工具的窗口资料时，也可以整理 Cookie、代理与原有配置，按官方窗口迁移说明批量导入。

### 2. 窗口同步器（Synchronizer）

窗口同步器包含在免费版中，用于在同一台电脑上将主控窗口的鼠标点击、页面滚动与键盘输入实时映射到多个从属窗口，适合多个环境需要执行完全相同的常规页面浏览或表单填写操作，减少人工逐窗重复点击的时间。

### 3. 内置 RPA（机器人流程自动化）

RPA 也包含在免费版中，允许用户通过预设步骤编排定时或顺序执行的页面任务，适合不懂复杂编程、但希望让单个或多个窗口按固定步骤完成常规日常维护的运营人员。

### 4. Local API（Selenium / Puppeteer 接入）

有开发能力的用户可以通过 Local API 程序化管理浏览器环境。开发者可以通过接口完成环境的创建、配置更新、启动与关闭，并直接拿到调试端口接入 Selenium 或 Puppeteer 等主流自动化框架，将指纹浏览器整合进自有的业务脚本与后台系统中。脚本运行时，也应把环境创建和打开额度纳入工作量预算。

### 5. MCP（Model Context Protocol）配置接入

希望连接 AI 助手或支持 MCP 协议的客户端时，可以使用官方 MCP 接入方案。该方案基于客户端的 Local API 与鉴权配置运行，连接前需核对客户端版本要求与 API 密钥设置。支持 MCP 的 AI 客户端可通过这些工具调用常规环境管理操作。
