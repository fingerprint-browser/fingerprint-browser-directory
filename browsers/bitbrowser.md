比特浏览器把独立环境、代理配置、窗口同步和自动化放在同一套客户端里。个人可以从免费版开始保存账号，等窗口数量增加或需要员工协作时，再扩充套餐，已有环境和操作流程可以继续使用。

## 免费版适合怎样使用？

免费版长期提供 **10 个环境，限 1 人使用**，每天最多创建 20 个、打开 50 次。不同账号可以分别保存 Cookie、代理和启动页面，使用时打开对应环境即可。

同步器、RPA 和 Local API 都包含在免费版中。除了手动管理账号，你还可以用少量窗口搭建重复操作流程，或调试已有的 Selenium、Puppeteer 脚本。

## 同步器、RPA 和 API 分别怎么用？

**窗口同步器**适合多个窗口执行相同操作。你在主窗口点击、滚动或输入，其他窗口同步执行，可以减少逐窗重复操作。

**RPA**适合步骤固定的任务。把页面操作编排成流程后，按顺序或定时执行，日常录入、页面检查等工作可以交给流程处理。

**Local API**面向有开发能力的用户。脚本可以创建、修改、启动和关闭环境，再接入 Selenium 或 Puppeteer，继续完成自己的业务操作。

**MCP**提供连接 AI 助手的入口。按官方说明配置 Local API 和密钥后，支持 MCP 的客户端可以调用环境管理工具，适合已经在使用 AI 处理浏览器任务的用户。

## 代理和旧环境怎么接入？

每个环境可以绑定独立代理，启动前检测连接、地区和端口状态。代理失效或参数填错时，可以在环境设置里直接排查。

已有其他工具的窗口资料时，可以整理原环境、Cookie 和代理，再按窗口迁移说明批量导入。迁移后继续使用对应的环境名称和分组，会更方便日常查找。

## 安装与后续扩展

客户端支持 Windows 10 及以上的 64 位系统，以及 macOS 12 及以上。Mac 提供 Intel 和 Apple Silicon 两种安装包。

个人管理几组账号，可以从 10 个免费环境开始；需要员工协作时，再考虑 50 窗口套餐。已有 AdsPower 流程或需要比较 GoLogin 云端运行的读者，可以继续看[比特与 AdsPower](../comparisons/bitbrowser-vs-adspower.md)、[比特与 GoLogin](../comparisons/bitbrowser-vs-gologin.md)。

## 从一个环境开始配置

先新建一个环境，填入便于辨认的名称和分组；有代理时，在同一环境中保存协议、主机、端口与认证信息。启动后检查出口 IP，再登录需要长期保留的工作账号。下次继续工作时，打开原环境即可沿用它的资料。

操作顺序见[代理配置指南](../guides/how-to-configure-proxy.md)。配置好后可按[检测指南](../guides/how-to-check-browser-fingerprints.md)核对 IP、WebRTC 和浏览器参数。
