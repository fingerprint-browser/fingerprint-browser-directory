Kameleo 同时提供 Chroma（Chrome 系）和 Junglefox（Firefox 系）浏览器，支持 Local API、官方 SDK 和 Docker。它的套餐除了环境保存数量，还按同时运行的浏览器数和使用时长分配资源，更适合已有脚本和部署需求的用户。

## 免费版的 300 分钟怎样计算？

Free 提供不限数量的本地环境、100 个云端环境、2 个浏览器并发和每月 300 分钟运行时间。环境只要处于打开状态，即使暂时没有操作，也会累计运行分钟；多个环境与团队成员共用这部分时长。

本地环境数量与云端保存名额分别计算。免费额度适合熟悉双内核、API 和开发流程，需要长时间保持窗口打开时，再看不限运行时长的付费档。

## API、SDK 和双内核

各套餐提供 Local API，SDK 支持 Python、JavaScript 和 C#。已有 Selenium、Puppeteer 或 Playwright 工作流，可以从环境创建、启动和调试连接开始接入；Playwright 也支持 Junglefox。

价格页针对获取实时指纹数据的请求列出速率：Free 为 60 次/分钟，Startup 为 120 次/分钟。其他接口按官方开发文档的具体限制安排。

## 桌面客户端和 Docker 分别适合谁？

手动查看环境可以使用 Windows 或 macOS 客户端；服务器部署可以使用 Linux 或 Windows Docker。容器中的浏览器在自己的基础设施运行，持久化目录、CPU、内存和并发需要一起安排。

需要 Linux 容器或 Firefox 系自动化时，Kameleo 的双内核与容器方式值得比较。主要是个人在桌面管理网页账号，希望免费使用同步器、RPA 和脚本，可以先看[比特浏览器的 10 个免费环境](bitbrowser.md)。
