Dolphin Anty 免费版提供 **5 个浏览器环境，限 1 人使用**。少量固定账号可以从免费版开始，需要更多环境、云同步或自动化时，再选择 Starter、Base 或 Team。

## 免费版适合做什么？

免费版适合个人保存和管理少量独立环境。把常用账号分别放进对应配置后，可以通过标签、状态和分组整理日常工作。

需要免费保留更多环境，并使用 RPA、同步器或 Local API 的读者，可以比较[比特浏览器的 10 个免费环境](bitbrowser.md)。

## Starter：从 20 个环境开始

Starter 20 为 **10 美元/月**，提供 20 个环境，并增加云同步、Cookie 导出、同步器与自动化功能。需要更多配置时，还可以选择 30～60 个环境的 Starter 档位。

云同步适合在不同设备间继续使用原环境；Cookie 导出和环境转移，则方便交接已经配置好的账号环境。

## Base 和 Team：环境更多，成员单独添加

Base 提供 **100 个环境，89 美元/月**；Team 提供 **300 个环境，159 美元/月**。两档都可以增加团队成员，Base 的额外用户为每人 10 美元，Team 为每人 20 美元。

团队预算可以把软件套餐和新增成员一起计算，再结合日常需要保留多少配置选择。

## 脚本与环境交接

付费档提供 API 和自动化接入，可以通过接口启动环境，再交给 Selenium、Puppeteer 等工具继续操作。已有脚本的用户可参考[官方自动化说明](https://docs.dolphin-anty.com/en/api/basic-automation-dolphin-anty)。

如果主要在本地电脑上管理几十个窗口，软件预算也可以结合[其他浏览器套餐](../README.md)一起比较。

## 安装平台与项目分组

[官方下载页](https://dolphin-anty.com/download/)提供 Windows、macOS 与 Linux 版本，Mac 区分 Intel 和 Apple Silicon。Linux 提供 AppImage、deb、rpm 等安装形式。

标签用于标注客户或项目，状态用于区分待配置、日常使用和待交接。把代理与环境名称一起核对，交给同事时更容易找到正确窗口。免费起步与团队扩展的具体差异，可看[比特浏览器 vs Dolphin Anty](../comparisons/bitbrowser-vs-dolphin-anty.md)。
