MoreLogin 的免费版提供 **2 个环境和 2 个用户**，适合两个人共同管理少量账号。免费功能包括窗口同步器、Local API，以及 Selenium、Puppeteer 接入，个人开发者也可以用它搭建小规模脚本流程。

## 两个人怎样使用免费环境？

2 名用户共享 2 个环境。适合一人负责环境和代理配置，另一人参与日常操作；如果两个人各自有多组账号，环境数量增加后就需要升级。

只有自己使用、但需要保留更多账号时，也可以比较[比特浏览器的免费版](bitbrowser.md)，它提供 10 个环境，并包含同步器、RPA 与 Local API。

## 免费的同步器和 API 能做什么？

同步器适合让两个窗口执行相同的点击、输入和滚动。Local API 则通过程序管理环境，可配合 Selenium 或 Puppeteer 调用浏览器，适合已有脚本或希望减少重复操作的用户。

这些功能可以从两个免费环境开始使用，流程搭建好后再按需要扩充窗口。

## 浏览器和云手机怎样选？

MoreLogin 同时提供浏览器环境与 Android 云手机。浏览器适合网页端账号操作，云手机用于需要移动系统和 App 的任务，费用分别计算。

免费版的 2 个环境是桌面浏览器配置。准备使用云手机时，可以在[产品官网](https://www.morelogin.com/)查看对应设备与计费方式。
