# Gemini 事实与自然表达复核提示词

你将收到一篇按本项目简报生成的 Markdown 稿件，以及对应页面简报和官方事实。请直接编辑成可交付稿，不重做选题。

核对五件事：
1. 逐项核对名额、计数周期、币种、月付/年付、成员口径和免费功能。删除无来源的性能、封号率、用户规模与第一人称体验。
2. 回答是否落在当前页面边界：详情页不要变成全品牌排行榜；比较页必须说明两款在哪些条件下分别适合；免费指南集中解释免费限制。
3. 删除没有增加信息的泛泛提醒和结尾。把机械的“先看/再看/最后”和“X 不等于 Y”改成具体事实或自然的判断，不只是换词。
4. 章节根据本页问题安排，允许长短段落混合；不要给全部产品换成完全相同的 H2 顺序。已回答的问题不再复制成 FAQ。
5. 检查 H1 唯一、相对链接与目标文件一致，来源链接对应附近的关键事实。无新事实时不增加免责声明、分数或图片占位。

输出完整修订后的 Markdown，保留本页要回答的问题、关键数据及必要来源。正文后用不超过 5 条列出实质修正；没有做过产品实测就不要把编辑过程写成验证结果。
